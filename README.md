# codex-kit

Codex로 데이터·웹 서비스 과제를 할 때 쓰는 점검용 스킬과 작업 규칙입니다. 특정 과제의 답이나 코드는 들어 있지 않습니다.

- `skills/data-quirks-check`: 데이터 전처리 함정 점검표
- `skills/submission-check`: 제출 전 점검표
- `AGENTS.md`: Codex 작업 규칙 (작업 폴더에 복사해서 사용)
- `templates/`: PLAN, COLLAB_LOG, HOW_TO_RUN 문서 틀

설치는 작업 폴더에서 `bash ~/codex-kit/install.sh` (윈도우는 `install.ps1`). 위 스킬과 함께 [obra/superpowers](https://github.com/obra/superpowers)(MIT)의 `verification-before-completion`, `systematic-debugging`을 Codex 스킬 폴더에 넣습니다.
